Helix Datasets

Our datasets test AI on anomalous math problems, prioritizing explanatory solutions over pattern-matching.

  • test.jsonl: Held-out test set (~15%).
  • val.jsonl: Validation set (~15%).
  • challenge.jsonl: Adversarial cases with tags like clone-trap, pattern-trap.

Schema Overview

Defined in schema.yaml, our schema enforces:

  • id: Unique problem identifier.
  • category: E.g., paradox, symbolic-confusion.
  • problem: The question text.
  • solution: Step-by-step explanation, not just answers.
  • tags: E.g., paradox, clone-trap, pattern-trap, information-as-power.
  • difficulty: E.g., hard, medium.
  • explanation_goals: E.g., dispel-pattern, causal-mechanism, counterexample-needed.
