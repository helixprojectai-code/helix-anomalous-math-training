Helix Datasets

Our datasets test AI on anomalous math problems, prioritizing explanatory solutions over pattern-matching.

  • test.jsonl: Core test set for model evaluation.
  • val.jsonl: Validation set for iterative training.
  • challenge.jsonl: Hard problems with tags like clone-trap, pattern-trap.

Schema Overview

Defined in schema.yaml, our schema enforces:

  • id: Unique problem identifier.
  • category: E.g., logic, probability, quantum.
  • problem: The question text.
  • solution: Step-by-step explanation, not just answers.
  • tags: E.g., paradox, clone-trap, explanation-required.
  • explanation_goals: Optional goals like dispel-pattern, causal-mechanism.
